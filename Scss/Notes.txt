@import directive is used to include one SCSS file into another 
- reusable

EXTEND
 
inherit the properties of one selector / styles into another
 
.selector1{
	some styles
}
 
.selector2{
	@extend .selector1
	//additional styles 
}
 
.................................................
 
MIXIN
 
-> block of reusable scss code that you can include anywhere
-> unlike extend we cannot add any extra feature where we are including the mixin
@mixin mixin_name{
	reusable
}
 
.selector{
	@include mixin_name
}
 
 
................................................
 
Functions
 
-> returns a single value (color , number , string...)
-> take parameters
 
@function func_name(parameters){
	@return value;
}
 
.selector{
	property : func_name(arguments)
}
