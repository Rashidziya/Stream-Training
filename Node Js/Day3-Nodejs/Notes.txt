Mongo DB -

-> It is developed by by MongoDB Inc in 2009.
-> It is written in c,c++ and javascript.
-> It is open source , NoSql DB. that provides us high perfromance and flexiblity.
-> MongoDB is also called as NoSql DB , because it does not depends on RDBMS.

-> MongoDB comes under the category of document oriented database.

Comparison Query operator -

$eq - It matches the value which is equal to the specifying value.

$ne - it matches value which is not equal to specifying value.

$gt - it matches value greater than specifying value.

$gte - it matches value greater than or  equal to specifying value.

$lt - it matches value less than the specifying value.

&lte - it matches value less than or equal to specifying value.

$in → Match Any of the Given Values
        { field: { $in: [value1, value2, ...] } }
        db.users.find({ city: { $in: ["Delhi", "Patna", "Kolkata"] } })

$nin → Not In (opposite of $in)

        { field: { $nin: [value1, value2, ...] } }
        db.users.find({ city: { $nin: ["Delhi", "Patna"] } })
    Finds users who do not live in those cities.
