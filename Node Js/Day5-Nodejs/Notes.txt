A Promise in JavaScript is an object that represents the eventual completion
 or failure of an asynchronous operation.

four states -

 --> pending - Initial state – operation is still in progress.

--> fulfilled - Operation completed successfully and returns a value. 

--> rejected - Operation failed and returns an error/reason.

--> settled - Final state – either fulfilled or rejected (not pending anymore).
