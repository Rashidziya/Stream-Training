Node Js-

-> Node Js is developed by Ryan Dahl in 2009
-> Node js is written in c/c++ and javascript
-> It is an open source Runtime environment.
-> Nodejs refers to the cross platform and highly extensible 
    programming platform.
-> The purpose of NodeJs is to execute the javascript code 
    outside the web browser.
-> save file via .js extension
-> NodeJs has its own v8e engine (It has the ability to interpret js code via v8 engine of google.)

Feature of NodeJs -

1) Single Threaded -
    When the NodeJs receives Request then it will process the first Request after that it
    will move to the second Request. (synchronous execution of Request).

NodeJs has Event-Loop that provides the illusion to the NodeJs as the multi-Threaded
programming Language.

2) Event-Driven - 

In this concept the main loop listens the Events & it triggers the callback() function,
So that it doesn't block the execution.

this concept makes Nodejs more scalable.

3) Asynchronous programming platform -

Because it uses the concept of callback() & Event-Loop , So that it provides the illusion that 
it can handle multiple Request simultaneously.

Note :- * All the API's in Nodejs is Asynchronous in Nature.


4). Streams -

-> It is the object used to Read the Data from the Source & Write the Data to Destination.
-> Helps us to optimised the processing time 


Advantages of NodeJs -

--> It is the single programming platform in which we can write FrontEnd and BackEnd (Both)

--> It is highly extensible Because we can extend it according to the demand & requirement.

--> It is fast in processing the Application Because it has it's own v8 Engine.

v8 Engine :- It is the javascript Engine which is embeded inside the browser
             and it execute the javascript code while browsing.

javascript is internally compiled by v8 with JIT(just in time).

synchronous code and Asynchronous code -

1. synchronous Code (Blocking Code) 
    It executes the code line by line.

Eg : 2 Task -

1) redaFile

2) printing Rashid 

So, here printing name will be done only after the completion of readFile(it take more).
    that's why it is called Blocking code.


2. Asynchronous code -

in this approach the code will be executed in a different order in which we have written the code.
with the help of callback() we can acheive the functionality of Asynchronous programming

1) readFile

2) printing name

So, here the printing name will be done first  and the readFile wil be called using callback()
when the task of readFile is completed.
