Working of HTTP/1 -

when the client sends Request to the server , then the browser process the Request initially 
and browser create a new Request to fetch the data from the server. so it is not a good approach
because user has to wait for long while the browser parses the Responses.
it also increase the processing time if processing time of the application will be increased
then the performance will get reduced.

workign of HTTP/2 -

It has new feature i.e - (push capabilities) 
- with the help of push capabilities the serve can send
asset to the browser initially and browser send back to the client.

HTTP/2 has one more feature i.e - Stream Headers

stream are indepenedent. and with the help of stream Headers(bidirectional sequence of frames).
we can   exchange data between the client and server within a single TCP connection.

Express Js -

-> It is the web framework for NodeJs 
-> It is asynchronous in Nature.
-> It is faster as compare to other platform. like ASP(active server pages) & JSP()


Features of ExpressJs -

1) Middleware -
-> It allows us to use Middleware to access the req and res objects.

2). Routing -
-> It allows us to define the routes to handle the different types of http Methods (GET,Post,Put);
3)
-> It has inbuilt error handling mechanism.

4) It is light weight in nature.
