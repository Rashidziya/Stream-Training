Angular
-------------

1. It is an open source typescript based
frontend framework which is used to create SPA ( Single Page Application ).

2. Angular extends html and makes the Application dynamic.

3. Angular is the product of Google. 

4. Typescript is more related to ES6 verison of Javascript and Typescript is partially object oriented.

----------------------------------

Difference between Traditional Application and Single Page Application (SPA) ?

Traditional Application:-
-------------------------

1. client server architecture  or 
request response model

Client --------http--------->Server
Server--------http---------->Client


eg- clicking button or submitting form 

2. when the request go to the server then in response the server will generate a new html page for every request, then processing time of the application will be increased and the performance of the application get reduced automatically.

3. That's why SPA comes in picture 

Single Page Application (SPA):-
--------------------------------

eg - Home About Products Contact

-> Pages are called as Components in Angular

-> Component is building block of Application.

-> Here if we hit on button the page 
doesn't refresh just the content gets changed.

-> It loads the single html page initially and dynamically it updates the content as per the user interact with the Application.

-> It will not reload the entire page for every request, then the processing time of the Application will be reduced and the performance of the application will get increased automatically.

----------------------------------------

Difference between Angular JS and Angular :-


Angular version 1.x is called as Angular JS 

-> it is based on MVC ( model view controller) we can define model, view, controller to create the structure of the Application.

-> Angular JS is written in Javascript 

-> Angular JS supports two way databinding, directives,components, pipes.

-> Angular JS doesn't support mobile development

-> Angular JS doesn't have cli.


Angular 2 and later versions are called as Angular 

-> Angular is completely rewritten of Angular JS. 

-> Angular is written in TypeScript 

-> Angular supports mobile development.

-> Angular follows component based approach.

-> Angular supports two way databinding, directives, components, pipes, APi, Services, dependency injection, Form Validation, Routing

Commands :-
-------------------


To install angular in our system use 
npm i @angular/cli@16.2.16 --g

To check Angular version : ng version

To create Angular Project : ng new projectname

To start Angular Application : ng server --o

Data Binding:-
--------------------

There are 3 ways to get the data from the controller-

1. interpolation
2. Array

Interpolation
----------------

  technology='Angular';
}

</h1>
